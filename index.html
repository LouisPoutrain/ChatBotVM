End-to-End Pipeline Architecture

VICTORIA deploys a dual-route retrieval framework coupling dense semantic embeddings with sparse lexical indexes, followed by neural cross-attention reranking and organizational directory resolution.

+---------------------------------------------------------------------------------------------------+ | VICTORIA SYSTEM DATA FLOW DIAGRAM | +---------------------------------------------------------------------------------------------------+ [ UTBOX WebDAV Cloud ] --(Differential Sync)--> [ Marker OCR Pipeline ] --> [ Structured Markdown ] | (Recursive Chunking: 800c) | +--------------------------------------------+ | | v v [ Dense Multilingual-E5 ] [ FastEmbed BM25 ] (1024-dim Cosine) (IDF-weighted Sparse) | | +---------------------+----------------------+ | v [ Qdrant Vector Engine ] (Collection: pdf2_documents) ^ | Hybrid RRF Search (k=60) | [ User Prompt / REST API ] ----> [ HyDE Query Expansion ] ----+ | (Selective Acronym Bypass) | +-------------------> [ RAC Organizational Router ] ---> [ Expert Referent Match ] | v [ Top-20 Candidates ] ---------> [ BAAI Cross-Encoder Reranker ] ----------> [ Top-5 Reranked ] | v [ Agentic Verification Loop ] [ Mistral / ILaaS LLM Engine ] | v [ Grounded Response + Contact ]
Hybrid Vector Space RRF k=60

Combines 1024-dimensional dense vectors from intfloat/multilingual-e5-large (semantic context) with sparse BM25 vectors (exact acronym tokens). Ranked using Reciprocal Rank Fusion to neutralize variance in scoring distributions.

Cross-Encoder Reranker BAAI bge-v2-m3

Filters initial top-20 candidates through an all-to-all cross-attention neural network. Calibrates passage relevance scores in [-10, +10], suppressing over 75% of superficial keyword false positives.

RAC Expert Router Organigramme Sémantique

Extracts laboratory affiliations and domain tags (AFRV, SPIV, RED, PJR, SAPS). Queries a dedicated Qdrant collection (infocontact) to inject verified human referent credentials into the final response.

API Specification & Quickstart

Deploy the FastAPI backend server, launch the Gradio diagnostic interface, or integrate the JavaScript web widget into your intranet.

1. Clone & Environment Installation

# 1. Clone repository
git clone https://github.com/LouisPoutrain/ChatBotVM.git
cd ChatBotVM

# 2. Setup virtual environment
python3 -m venv .venv
source .venv/bin/activate

# 3. Install production dependencies
pip install --upgrade pip
pip install -r requirements.txt

2. Launching Services

# Start FastAPI REST server (Port 8600)
uvicorn Interface.fastapi_rag_wrapper:app --host 0.0.0.0 --port 8600 --reload

# Start Gradio interactive interface
python Interface/gradio_rag_wrapper.py

# Or start full stack with Docker Compose (FastAPI + Qdrant container)
docker-compose up -d

3. REST API Interaction

curl -X POST http://localhost:8600/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "question": "Comment passer l'\''HDR ?",
    "session_id": "session-101"
  }'
